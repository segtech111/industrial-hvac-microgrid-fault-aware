# Industrial dataset

The raw industrial AHU dataset is intentionally not committed to this public repository.

Required local/Colab file:

`Data_Article_Dataset(1).csv`

The integrated workflow uses the dataset for AHU data-quality assessment, anomaly/fault-risk monitoring, future risk prediction, HVAC demand prediction and fault-aware optimization.

The dataset does not provide measured microgrid frequency or BESS signals. Those remain simulated in the independent microgrid model.

Do not redistribute the raw dataset unless you have permission from the dataset owner/source.
