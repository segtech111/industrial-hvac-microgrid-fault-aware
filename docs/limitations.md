# Limitations and Scientific Scope

1. The industrial AHU dataset has no verified ground-truth fault labels; anomaly scores must not be reported as supervised fault-classification accuracy.
2. The dataset has no measured microgrid frequency or BESS response; frequency and BESS behavior remain simulated.
3. HVAC electrical demand should be calibrated to a known site electrical base before making site-level microgrid power claims.
4. The current HVAC optimizer is a data-driven supervisory MPC-style layer. A future extension can add an explicit learned zone-temperature dynamics model and hard comfort constraints.
5. Synthetic fault injection, if used, should be reported only as a clearly labeled robustness experiment.
6. Final integrated performance metrics must be generated by executing the complete notebook on the intended dataset; no unexecuted results should be presented as measured or validated.
